Privacy policy

Effective October 6, 2026.

Taelos Tasks is a personal tool with one user, its owner. It is not offered to anyone else.

What it accesses

With the owner's consent, it uses the Google Tasks API to read, create, and update tasks in the owner's own Google account.

How the data is used and stored

Task data is used only to keep the owner's to-do list in sync with their personal assistant. It is processed on the owner's own home server. Access credentials are stored in the owner's private secrets manager.

Sharing

Task data is not sold, shared with third parties, or used for advertising.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
